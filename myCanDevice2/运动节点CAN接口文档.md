# CanDevice2 上位机接口文档

版本：V1.0
适用对象：ESP32-S3 仪表主机（上位机）与 CanDevice2（STM32 A 运动节点，STM32F103C8T6）

## 1. 总体约定

- CAN 版本：CAN 2.0A，11 位标准数据帧
- 波特率：500 kbit/s
- 数据字节序：小端 Little-Endian（多字节字段低字节在前）
- 数值字段采用整数 + 缩放因子传输
- 周期报文由节点主动发送，控制报文由上位机主动发送
- 上位机需在物理总线一端安装 120 Ω 终端电阻（总线两端各一个）

## 2. 节点身份与 ID 分配

本设备为 **STM32 A 运动节点**。

```text
0x100~0x1FF   本节点业务数据（A 运动节点）
0x600~0x6FF   CAN IAP 升级
0x700~0x7FF   心跳与诊断
```

## 3. 本节点上报报文

### 3.1 0x100 运动状态（50 Hz，DLC 8）

| 字节 | 字段 | 类型 | 单位 | 说明 |
|------|------|------|------|------|
| 0~1 | 车速 | uint16 | 0.01 km/h | 当前无轮速传感器，恒为 0 |
| 2~3 | 转速 | uint16 | rpm | 当前无编码器，恒为 0 |
| 4~5 | 横滚角 | int16 | 0.01° | 由加速度计算，小端 |
| 6~7 | 俯仰角 | int16 | 0.01° | 由加速度计算，小端 |

横滚角 = atan2(ay, az)，俯仰角 = atan2(-ax, sqrt(ay² + az²))，均为对重力矢量估算的角度，静止时稳定，运动时含动态误差。

### 3.2 0x101 三轴加速度（50 Hz，DLC 8）

| 字节 | 字段 | 类型 | 单位 | 说明 |
|------|------|------|------|------|
| 0~1 | X 轴加速度 | int16 | 0.001 g | 小端 |
| 2~3 | Y 轴加速度 | int16 | 0.001 g | 小端 |
| 4~5 | Z 轴加速度 | int16 | 0.001 g | 小端 |
| 6 | 运动状态 | uint8 | - | 位标志，见下 |
| 7 | 数据计数器 | uint8 | - | 每帧递增，用于丢帧检测 |

运动状态位：

```text
Bit2：IMU 数据有效（1=有效；IMU 故障时为 0）
```

示例：静止时 Z 轴约 1 g，即约 1000（0.001 g 单位）。

### 3.3 0x110 轮速和里程（20 Hz，DLC 8）

| 字节 | 字段 | 类型 | 单位 | 说明 |
|------|------|------|------|------|
| 0~1 | 轮速 | uint16 | 0.01 km/h | 无传感器，恒为 0 |
| 2~5 | 累计里程 | uint32 | 0.01 km | 恒为 0 |
| 6~7 | 霍尔脉冲计数 | uint16 | - | 恒为 0 |

当前为占位报文，待轮速/编码器硬件接入后填充。

### 3.4 0x701 节点心跳（1 Hz，DLC 8）

| 字节 | 字段 | 类型 | 说明 |
|------|------|------|------|
| 0 | 节点状态 | uint8 | 0=启动中，1=正常，2=降级，3=严重故障 |
| 1 | 软件版本 | uint8 | 当前 0x01 |
| 2 | CAN 接收错误计数 | uint8 | 读取 ESR.REC |
| 3 | CAN 发送错误计数 | uint8 | 读取 ESR.TEC |
| 4 | 传感器故障位 | uint8 | Bit0：IMU 故障 |
| 5 | 任务运行状态 | uint8 | 1=正常 |
| 6~7 | 运行时间 | uint16 | 单位 s，小端，超过 65535 s 回绕 |

### 3.5 0x080 紧急故障

严重故障时立即发送，DLC 8。当前固件未主动触发，格式预留：

```text
Byte0：故障节点（本节点 A=0x01）
Byte1：故障等级（0提示/1警告/2严重/3紧急）
Byte2~3：故障代码
Byte4~5：故障参数
Byte6：是否锁存（0/1）
Byte7：故障序号
```

## 4. 上位机 → 本节点控制报文

### 4.1 CAN IAP 升级（0x600 控制 / 0x610 应答）

上位机通过 0x600 下发命令，单帧格式：`Byte0 = 命令码`，`Byte1 = 会话序号`（回显用）。

| 命令码 | 命令 | 当前实现 |
|--------|------|----------|
| 0x01 | 查询节点信息 | 已实现：应答后 Byte7 返回软件版本 |
| 0x02 | 开始升级 | 已实现：应答"准备升级"后执行软件复位 |
| 0x03 | 发送固件数据块 | 未实现 |
| 0x04 | 结束传输并校验 | 未实现 |
| 0x05 | 激活新固件并复位 | 未实现 |
| 0x06 | 查询升级进度 | 未实现 |
| 0x07 | 取消升级 | 未实现 |

**升级应答 0x610（DLC 8）**

| 字节 | 字段 | 说明 |
|------|------|------|
| 0 | 应答命令 | 回显原命令码 |
| 1 | 状态码 | 见下 |
| 2 | 会话序号 | 回显命令帧 Byte1 |
| 3~4 | 当前块号 | 小端 |
| 5~6 | 错误码 | 小端 |
| 7 | 重试次数 / 扩展 | 查询节点信息时回传软件版本 |

状态码：

```text
0x00 成功          0x80 固件长度错误
0x01 准备升级      0x81 数据块 CRC 错误
0x02 接收中        0x82 完整固件 CRC32 错误
0x03 等待重传      0x83 Flash 写入失败
0x04 校验成功      0x84 版本非法
0x05 升级完成      0x85 会话超时
                  0x86 目标地址非法
```

**IAP 流程（当前阶段）**

```text
上位机                              CanDevice2
  |-- 0x600: 0x02 会话 -------------->|
  |                                   | 回 0x610: 0x02 0x01 会话
  |<-- 0x610: 准备升级 ----------------|
  |                                   | 软件复位 (NVIC_SystemReset)
  |<-- 复位后 0x701 心跳重启 -----------|
```

注意：当前固件**尚未包含 Bootloader**，收到 0x02 后仅执行软件复位，应用随即重新运行。后续固件数据接收（0x03~0x07）、双区存储与回滚需在 Bootloader 中实现。

## 5. 接收超时与状态判断（上位机侧）

```text
0x100 运动状态：超过 100 ms 未收到，数据无效
0x101 三轴加速度：超过 100 ms 未收到，数据无效
0x110 轮速和里程：超过 100 ms 未收到，数据无效
0x701 心跳：超过 3 s 未收到，节点离线
```

- 超时后不得继续把旧数据显示为正常数据，应显示"数据无效"或"节点离线"。
- 0x101 Byte6 的 Bit2 为 0 时，即使收到报文，加速度数据也视为无效。
- 0x701 Byte0 为 2（降级）时表示 IMU 故障，姿态/加速度报文仍在发送但标志位为 0。

## 6. 上位机实现建议

- 总线波特率固定 500 kbit/s。
- 订阅 ID：0x100、0x101、0x110、0x701、0x610；发送 ID：0x600。
- IAP 一次只升级一个节点；升级期间避免大量诊断报文，保证总线负载在 30% 以下。
- 收到 0x610 的 0x02/0x01 应答后，等待节点心跳重新出现以确认复位生效。
