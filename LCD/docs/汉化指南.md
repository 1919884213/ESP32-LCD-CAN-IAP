# 汉化与中文字体使用指南

> 适用范围：本工程（ESP32-S3 + LVGL 9.5.0）。UI 已整机中文化，本文说明**以后如何继续使用/新增中文标签**。

## 1. 字体体系（了解即可）

| 字体 | 角色 | 覆盖 |
|---|---|---|
| `lv_font_source_han_sans_sc_14_cjk` / `_16_cjk` | 中文主字体（LVGL 内置，`lv_conf.h` 已开启） | ASCII + 约 1338 个常用字/部首 |
| `font_cn_supplement_14` / `font_cn_supplement_16` | 补充子集（`main/UI/asset/`，fallback） | 内置缺失、本工程用到的字 |
| `font_cn_weather_24` | 天气状况大字（24px，独立） | ASCII + 和风天气中文状况全集 |

- 内置字体为 `const`，LVGL v9 无 `lv_font_set_fallback()`；`ui_helpers.c` 用**结构体拷贝**接 `.fallback`，对外提供：
  - `ui_font_zh_14()` / `ui_font_zh_16()`：内置 + 补充 的字体链
  - `&font_cn_weather_24`：天气大字
- 对齐一致性：内置与补充的 `(line_height − base_line)` 相等（14:13、16:15），fallback 不错位。

## 2. 怎么写中文标签

**优先使用辅助函数**（它们已自动使用中文字体）：

```c
lv_obj_t *ui_create_title(parent, "中文标题");     // 16px 强调色
lv_obj_t *ui_create_caption(parent, "中文说明");   // 14px 灰色
```

**数值/自定义字体的标签**：凡含中文，字体必须传中文链，否则显示方框：

```c
ui_create_value(parent, "已连接", ui_font_zh_14());
// 或对已有标签设置字体
lv_obj_set_style_text_font(label, ui_font_zh_16(), LV_PART_MAIN);
```

**天气状况大字**：

```c
ui_create_value(parent, "雷阵雨", &font_cn_weather_24);
```

**注意**
- 纯数字/Latin 标签（速度、时间、`%RH` 等）可继续用蒙太字体，不必改。
- `LV_SYMBOL_*` 图标在内置 CJK 字体中已含，放心与中文混排（如 `LV_SYMBOL_HOME " 首页"`）。
- **不要**给含中文的标签指定蒙太字体（`&lv_font_montserrat_*`）。
- 源文件编码须为 **UTF-8**（本工程已是）。

## 3. 新增中文文案后：缺字检查与字体再生成

> 内置 + 补充字库是**固定集合**。新增文字若含未收录字，会渲染成方框。两步解决：

### 3.1 检查缺字

运行 `tools/` 下校验脚本（见下文脚本来源），或临时用：

```powershell
[Console]::OutputEncoding=[System.Text.Encoding]::UTF8
$b=Get-Content managed_components/lvgl__lvgl/src/font/lv_font_source_han_sans_sc_16_cjk.c -Encoding UTF8 -TotalCount 4|Select-Object -Last 1
$s=Get-Content main/UI/asset/font_cn_supplement_16.c -Encoding UTF8 -TotalCount 4|Select-Object -Last 1
$new="你新增的中文"
$new.ToCharArray()|ForEach-Object{ if(-not $b.Contains([string]$_) -and -not $s.Contains([string]$_)){ Write-Host ("缺: $_") } }
```

### 3.2 重新生成补充子集（14/16 都要）

用与现有一致的参数，**把缺字并入 `--symbols`**：

```bat
npx --yes lv_font_conv --font C:\Windows\Fonts\SourceHanSansCN-Regular.otf ^
  --symbols 严为云储冰况冻凇创务劲升卷发启固址复夹姿导尘带序强微态扬据无暴板极标槽沙浓浮湿滑激灯炎烈热照爽版狂环疾码离称签级线细络绪网螺认询误请读败距载输过运进连酷错镜闲间阴阵陀际雷雹雾霾页风飓驶驾验默龙…·伴并短时至<新增字> ^
  --size 14 --bpp 4 --format lvgl --force-fast-kern-format --no-compress --no-prefilter ^
  -o main/UI/asset/font_cn_supplement_14.c
```

> 把 `--size 14` 改成 `16` 生成 `font_cn_supplement_16.c`。
> 生成后两个文件里 `#include "lvgl/lvgl.h"` 若被写出，需改回 `#include "lvgl.h"`。

### 3.3 天气大字（仅当天气词库增加）

把新天气词的字并入 `--symbols`，加 `-r 0x20-0x7f`，`--size 24`，输出 `font_cn_weather_24.c`。
当前 24px 词库已覆盖和风天气全部中文状况（含"雷阵雨并伴有冰雹"）。

### 3.4 再生成脚本与校验脚本（可复用）

- 生成脚本：`C:\Users\lrd\AppData\Local\Temp\opencode\cnfonts\gen_fonts.js`（14/16）与 `gen_weather24.js`（24px）
- 覆盖率校验：`C:\Users\lrd\AppData\Local\Temp\opencode\cnfonts\check_coverage.py`（提取字符串字面量，比对内置∪补充）

## 4. 其他汉化点备忘

- 天气接口已 `lang=zh`（`main/HTTPS/qwWeather/weather.h`）；`weather_icon_for_condition()` 用中文关键词匹配图标（雨→雨图；雷/暴/雪/冰/雹/飓/龙卷/沙/尘→暴雨图；云/阴/雾/霾→多云图；其余→晴）。
- IAP 状态文案在 `main/Can/Can.c`（`s_iap_status`），如"发送 %u%%"，缓冲区 24 字节足够。
- OTA 下载状态缓冲 `s_download_status_buf` 64 字节，中文按 UTF-8 3 字节/字，注意别超长。
